# v0.2-wms

2026-11-10，WarehouseTwin 第二阶段版本。该阶段把入库、质检、批次预占和盘点接入 PostgreSQL，并让业务提交后的库存变化反映在仓库场景和台账。

[WMS 操作录像](../../reports/day-14-demo.webm) · [验收报告与覆盖矩阵](../../reports/day-14-acceptance.md)

## 可演示的流程

从入库单收货 3 件进入质检位，通过待检预警定位 QC-01，查看 3D 和批次详情。质检放行后，同一批次的可用量增加，现存不变。接着对储位盘点，录入实数并审批，最后筛选调整流水和运行只读对账。

出库预占可从出库页面操作。取货、在途、暂存与发运现阶段由内部领域命令和集成用例验证。浏览器录像演示人工 WMS 业务，机器人 runner、路径规划、自动搬运和实时同步属于后续阶段。
