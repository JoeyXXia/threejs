# v0.1-scene

日期：2026-11-04。第 1 周“业务数据与第一版 3D 场景”阶段发布，Git 标签 `v0.1-scene`。

## 可演示能力

会话与仓库授权；PostgreSQL 中的版本化布局、合成 SKU/批次、余额及期初流水；API 驱动的参数化仓库；稳定货位身份拾取与批次详情；搜索定位、正交/透视、区域筛选、2D 替代入口；错误态和无 WebGL 降级。

[15 秒演示](../../reports/day-07-demo.webm)：搜索并实际点选有货/空货位，切换 2D 对照，整页刷新并恢复汇总。完整结果见 [Day 7 验收](../../reports/day-07-acceptance.md)。

## 数据与验证

普通 seed：A 仓 17 个货位，现存 62、可用 55、预占 0、HOLD 7。合成样本通过事务写入真实数据库和 SEED 期初流水；前端展示 API 返回的数据。布局与 inventory 分别以一致事务读取，再由前端做版本配对；当前使用手动刷新。

2026-11-04 本地验证：check、35 项前端、44 项真实 PostgreSQL/API 测试通过，DB 重启后对账 0 差异；两个真实射线详情与 2D/API 一致，17 行列表数量和整页刷新持久性验收通过。应用基线 `b993d9f` 的 [CI 成功记录](https://github.com/JoeyXXia/threejs/actions/runs/41392140712)与发布提交的 CI 分开核实。

## 运行与复现

按根 [README](../../README.md)准备 Node/pnpm，冻结安装、Prisma 生成、启动本地 PostgreSQL、迁移和 seed，再 `pnpm dev`。开发账户密码只保存在本地 .env。独立浏览器验收采用[测试环境说明](../../scripts/browser-checks/README.md)，不用开发凭据。

```powershell
pnpm check
pnpm test:unit
pnpm test:integration
git show v0.1-scene --no-patch
```

## 当前限制

设备为软件模拟；此版本没有运输任务、机器人 runner、路径规划、收货/质检/业务预占命令、Socket 实时投递、历史回放或生产部署。QA 维护命令不属于产品业务。保留 chunk/Three.Clock 警告，没有 FPS、吞吐或长期资源稳定性成绩。

提交与标签通过 Git 发布；此说明随标签版本保存，不声称已经建立 GitHub Release 对象或部署在线站点。
