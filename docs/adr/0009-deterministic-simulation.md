# ADR 0009：纯模拟核心与三种时钟

日期：2026-11-12（Asia/Shanghai）。状态：Day 17 采用；数据库 runner、租约和浏览器插值尚未实现。

## 背景和决定

Day 15/16 已有完整布局导航网格和有界 A*。Day 17 将 A* 提取到 `packages/simulation/src/astar.ts`，以结构化 Grid 接口替代对前端模块的类型依赖。原前端入口只重导出函数，既有 BFS 对照测试不改变。布局构建继续留在前端，不为共享而引入业务契约依赖。

模拟核心使用不可变、可 JSON 序列化的 `SimulationState`。状态记录 schemaVersion、seed、显式 PRNG 状态、布局身份/版本和阻塞格、tick、逻辑时间、暂停标记及单车状态。初始化复制并冻结地图和坐标；接受路径时同样复制并冻结。旧快照不会随下一步移动而改变。

`createSimulation → applyCommand → step → stateSummary` 是最小入口。输入来自调用方，不读取 Query、Zustand、Three.js、数据库或全局随机数。随机算法为 Mulberry32；uint32 seed 含 0 均合法。初始化只消费一次 PRNG，为未显式指定电量的车辆生成 9000–10000 基点的演示初值。显式 battery 参数仍记录该 PRNG 状态，移动过程不再随机耗电。

## 三种时钟

1. **逻辑时钟**：默认每次 `step` 推进 250ms，最多移动一格；暂停返回原状态。逻辑时间不依赖机器执行一次 step 花了多久。
2. **外部墙钟/单调耗时**：`createFixedStepRunner.advance(elapsedMs)` 接收调用方测得的整数毫秒差。它累积余数，够一步才调用 step；不创建 interval/timeout。接入时应先对单调绝对时间取整再求差，不能对每一帧小数 delta 分别向下取整而丢时间。
3. **渲染时钟**：留给 Day 18 的显示插值。它只展示已确认状态，不能根据渲染帧数推进业务或扣库存。

固定步长适配器默认单次最多 8 步。超出的完整步对应墙钟时间被丢弃，返回 `lag=true` 和 `droppedMs`，不足一步的余数保留，不留下无限追赶队列。该上限是实现选择，不是性能测量结论。卡顿时逻辑故意变慢；只有**未触发丢弃且输入总耗时相同**时，不同分片方式应得到相同 tick。确定性核心重放应记录明确 tick/命令顺序，而不是根据旧墙钟重新补跑。

暂停转换会丢弃当前不足一步的余数，暂停期间的 elapsed 不参与累计；恢复从新输入开始。重复 pause/resume 不额外推进时间，重复 resume 不丢弃当前余数。适配器余数不包含在核心状态摘要内；本轮没有实现持久化恢复或跨进程 runner。

## 路径、方向、电量和状态

仅一台软件机器人。命令包括 pause、resume 和 route。route 必须携带当前布局身份及版本，路径包含当前起点，各点为合法可走格，每步 Manhattan 距离为 1；拒绝斜走、重复格停步、穿墙、越界和运行中替换路径。相同起终点的单点路径立即空闲。

每次移动扣 1 电量基点；10000 代表 100%，使用整数避免累积浮点误差。闲置不扣电。0 电量进入 DEPLETED，保持原地和剩余路径，不会瞬移或出现负电量；充电、低电量任务准入另日实现。方向约定 x 增为 E、x 减为 W、z 增为 S、z 减为 N。状态为 IDLE、MOVING、DEPLETED，暂停是独立的全局标记。

`stateSummary` 对状态的有序字段、标准化坐标和去重排序的阻塞格生成带 `sim1-` 前缀的 FNV-1a 32 位诊断摘要。它可用于同版本测试比对，但存在碰撞，不是安全签名，也不能替代完整状态比较。算法升级需要同步升级 schema/摘要版本并保存旧规则，不能声称跨任意源码版本确定性。

## 权威与提交边界

PostgreSQL 仍是布局、库存、任务、分配和审计的权威。纯模拟状态目前仅为内存演示状态，不把客户端位置或到达事件视为库存过账凭证。Query 缓存和 Zustand UI 状态不变，R3F 尚未消费模拟快照。

本轮没有写事务或实时同步，也没有 Socket、Redis、队列、runner owner 或数据库检查点。后续按计划增加服务端 runner：事务外计算路径，提交时校验布局/状态版本；以合法 owner/epoch/expectedTick 写状态、账本和事件后，才向前端发布。A* 的性能时钟仅限制搜索预算；限时中止结果本来就可能随机器负载不同，不用于决定确定性 tick。核心只消费已验证的显式路径。
