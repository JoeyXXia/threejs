## 同步协议和限制

- `GET /spaces/:spaceId/warehouses/:warehouseId/snapshot` 一次返回布局、库存、车队、单车选项及水位，同一数据库快照；旧读端点保留。Day30 无新迁移，沿用 Day29 事件元数据迁移。
- UI 先订阅，再取一致快照。以已发布水位续订；对乱序用受限缓冲按连续 seq 排序、去重。缺口优先读现有 HTTP 事件历史；`CURSOR_EXPIRED`、历史 410 或缓冲超限时重新订阅并读完整基线。不依据事件时间戳排序。
- 每个连接代只顺序发起同步请求；切换连接会取消旧代并丢弃迟到响应。恢复时通过完整快照更新库存和位置，不实现可独立回放的业务 reducer。活动车队在连续提交期间会多次读取完整快照，不承诺吞吐、页面帧率、生产延迟或跨实例一致投影。
- 离线/陈旧状态可读最后确认快照，场景写操作停用；收到明确撤权或会话过期时隐藏缓存。浏览器之外已有的 HTTP 命令仍由服务端授权与业务事务校验。
